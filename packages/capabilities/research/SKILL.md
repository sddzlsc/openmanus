# 调研能力包

## 规则

1. 每个关键结论必须带来源（链接 + 访问日期）；无法验证的内容标注"待确认"。
2. 对比类任务先输出对比表，再写结论；表格列固定为：对象、关键事实、来源、可信度。
3. 至少覆盖三类来源：官网/官方文档、权威媒体、第三方数据；单一来源不构成结论。
4. 大规模类比（几十到上百个对象）走并行子智能体（M5 的 Wide Research），并把每个子任务的来源合并去重。
5. 最终交付 `research-brief.md`（doc）与可选的对比表 `comparison.csv`（dataset）。

## 并行研究（Wide Research）

对象数量决定研究方式，**不要用一个智能体串行翻完所有对象**：

| 对象数 | 方式 |
|---|---|
| 1–4 | 自己顺序研究即可 |
| 5–20 | 用 `subagent` 工具**并行派发 3–6 个子智能体**，每个负责 2–4 个对象 |
| 20+ | 分批派发（每批 ≤ 8 个子智能体），每批完成后合并，再进入下一批 |

子智能体的任务描述必须写成「**研究范围 + 需要产出哪些字段 + 必须附来源链接**」，
例如：「调研 {A、B、C} 三家公司的产品、融资、技术路线；每个对象给出 3–5 条事实，
每条事实必须附来源 URL 与访问日期；输出 JSON 数组」。

**合并规则**：所有子智能体返回后，先按来源去重，再按对象合并成一张对比表；
冲突的数据保留两条并标注来源，不允许自行取舍。合并结果必须包含：

1. 对比表（对象 × 字段）；
2. 每个对象的来源清单；
3. 三条以内的结论，以及"数据不足/未验证"的显式标注。

进度要写进时间线：每派出一个子智能体就打印一行 `派出子智能体：<对象列表>`，
每个返回后打印 `子智能体完成：<对象列表>（来源 N 条）`，便于用户看到并行进度。
