# 阶段三执行计划（Studio / 团队 / 开放平台 / 插件市场）

阶段三不再依赖"把某个能力做出来"，而是把平台从"单账号工具"升级成"可运营的产品"。
下面每一节都写成可直接开工的形态：交付物、接口、验收标准、依赖。

## 1. 工作室（Studio）——专业产物编辑器

**目标**：用户不只能拿到文件，还能在网页里继续加工。

| 子项 | 交付物 | 技术路径 | 验收 |
|---|---|---|---|
| 视频时间线 | 分镜/片段列表可拖拽排序、替换素材、导出 mp4 | 前端 canvas 时间线 + 沙箱内 ffmpeg 合成；片段与配音存在工作区 `media/` | 用户能替换背景音乐并重新导出，时间线状态可回放 |
| 设计画布 | 海报/封面画布，图层可拖动、导出 png/pdf | 前端 Konva 画布；素材来自图片生成或用户上传 | 画布内容与最终导出像素一致（允许 1px 误差） |
| 幻灯片精修 | 网页内改文案/换配色后重新导出 pptx | 复用 `office` 能力包：解析现有 pptx → 修改文本/主题色 → 重新生成并跑 `check_pptx.py` | 修改后校验 0 问题，且几何与模板保持一致 |
| 游戏/交互 | 可玩 HTML5 小游戏（Canvas/Phaser），分享链接可直接玩 | `web` 能力包升级版模板 + 资源生成 | 生成后分享链接打开即可玩，移动端不横向滚动 |

**共用改动**：交付物新增 `editor` 元数据（可编辑类型 + 编辑器路由），前端新增 `/studio/[artifactId]` 路由；
编辑器所有的保存动作写回工作区文件并追加 `artifact/updated` 事件（时间线可见）。

## 2. 团队、SSO 与开放 API

| 子项 | 交付物 | 接口/模型 | 验收 |
|---|---|---|---|
| 组织与成员 | `Organization` / `Membership(role: owner/admin/member)`；邀请链接 | `POST /api/orgs`、`POST /api/orgs/:id/invites`、`GET /api/orgs/:id/members` | 成员只能看到本组织项目；owner 可移除成员 |
| 角色权限 | 项目/交付物按组织隔离，管理员可查看用量 | 在 `store` 层加 `orgId` 过滤 | 跨组织访问返回 404（不泄露存在性） |
| SSO | OIDC 登录（企业微信/钉钉/飞书/阿里云 IDaaS） | `POST /api/auth/sso/:provider/callback` | 企业域名自动路由到 SSO，留手机号登录兜底 |
| 开放 API | 个人访问令牌（PAT）+ 任务/交付物 REST | `POST /api/tokens`、`GET /v1/tasks`、`POST /v1/tasks`、`GET /v1/artifacts/:id` | 用 PAT 可创建任务并轮询到交付物；令牌可撤销、带 scope |
| Webhook | 任务完成回调 | `POST /api/webhooks`，签名 HMAC | 任务完成 3 秒内收到回调，签名校验通过 |

## 3. 计费与配额

| 子项 | 交付物 | 说明 |
|---|---|---|
| 计量 | 按 token / 容器分钟 / 生成次数计费（已有 `UsageRecord`） | 阶段三把估算 token 换成真实用量（dsh headless 无用量输出 → 用 provider 侧账单或代理层统计） |
| 套餐 | 免费（含基础额度）/ 专业（订阅）/ 企业（自定义） | 套餐决定配额上限与并发数 |
| 支付 | 微信支付 + 支付宝（企业资质必需） | 只在"已有主体 + 已完成生成式 AI 备案"后开放 |
| 账单页 | 用量趋势、余额、充值记录 | 前端新增 `/billing` |

**前置依赖**：生成式 AI 服务备案、支付商户号、发票能力。技术上不阻塞，商务上必须先办。

## 4. 插件与子智能体市场

**核心抽象**：能力包（capability pack）= 目录 = `SKILL.md` + 脚本 + 模板；
执行器（executor）= dsh 子智能体 provider（in-process / codex / claude-code / browser）。

| 子项 | 交付物 | 接口 | 验收 |
|---|---|---|---|
| 清单接口 | 列出能力包与执行器、版本、可用状态（凭据是否就绪） | `GET /api/catalog` | 市场页数据与镜像内实际文件一致 |
| 租户开关 | 每个组织可启用/禁用能力包 | `POST /api/orgs/:id/capabilities/:id` | 禁用后任务不再加载该 skill（时间线里可见"未加载"） |
| 安装 | 从 npm 或私有源安装能力包到镜像/租户层 | `dsh plugin add` + 能力包 manifest | 安装后新任务立即生效，无需重启控制面 |
| 审核 | 签名 + 权限声明（可访问网络/文件/凭据） | manifest `permissions` 字段 | 未声明权限的包在任务里被拒绝执行 |
| 市场 UI | 卡片列表、详情、启用开关、用量统计 | 前端 `/marketplace` | 非管理员只读，管理员可开关 |

## 5. 连接器与自动化

| 子项 | 交付物 | 验收 |
|---|---|---|
| 连接器（M4 遗留） | 飞书、企业微信、钉钉、GitHub、Notion + 通用 MCP | 授权一次后可在任务里读写对应资源；令牌过期有提醒 |

| 云电脑 | 常驻容器 + 持久盘（M5） | 长驻服务（机器人/数据库）可 7×24 运行，重启后自动续跑 |
| 并行研究 | dsh subagent 扇出 + 进度网格 | 20 个子智能体并发研究，合并为一份带出处的报告 |

## 7. 风险与前置条件

- **备案与支付**：公开收费前必须完成生成式 AI 服务备案；支付需要企业资质与商户号。
- **执行器凭据**：Codex / Claude Code 采用 BYOK；平台侧统一供给需要海外主体与网络通道，合规风险高。
- **成本**：视频生成与浏览器任务最贵，必须在市场上就标明单位成本并纳入配额。
- **开发量**：本文件 6 个切片按 2 周一个估算约 12 周（单人 + AI 协作），其中 Studio 编辑器与计费是两处最大的不确定项。
